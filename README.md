# AI Influencer Studio

A focused web app for creating AI influencer characters. Pick a set of visual traits, generate a character, then browse an explore feed where any result can be recreated and tweaked. It's a leaner take on the kind of AI influencer studio that usually hides this flow behind an onboarding quiz and a paywall — here you land straight in the builder.

## What you can do

- Build a character from a trait panel — character type, gender, build, hairstyle, hair colour and more — with a live summary and a randomise button.
- See the credit cost of a generation before you run it.
- Explore a gallery of characters and hit Recreate to load any character's traits back into the builder.
- Keep your history locally in the browser, so there's no sign-up and the link works for anyone.

## Tech stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Vercel for deployment

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to use it.
